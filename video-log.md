# Video style registry (Reels)

Rule (Ali, 23 Nov 2026): every new video must have its own identity. Before building one, read the last 7 entries and make sure today's differs on ALL of: art direction, layout/template, palette, typography pairing, animation technique, transitions, music (genre, instrumentation, BPM, source), pacing/structure, and length. Write each renderer fresh; don't adapt a previous reel script. Keep only the brand layer constant: the subtle LinkWin mark, linkwinco.com and a refined end card styled to match the video.

## Patterns that became repetitive (17–22 Nov): retire these for now
- Always 24 s long. Vary between about 12 and 35 s.
- The same fonts every time (Oswald 600 + Manrope + Playfair Display). Use new pairings.
- A photo window on top with Ken Burns and an info deck underneath, plus red-edged wipes.
- Seal red #AC3E33 as the accent in every video; the same "seal signature" end card.
- Bare synthesized music beds built from scripts (*-reel-audio.py) with similar tone and tempo. Use professional, license-clear tracks or sample-based compositions matched to the mood.
- Ivory/paper backgrounds alternating with dark ink.
